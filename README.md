# XContábil

🔗 [Acesse o site](https://sites.xweb.com.br/xcontabil/)

O **XContábil** é um site institucional voltado para escritórios de contabilidade, criado com foco em presença digital, captação de leads e apresentação dos serviços contábeis de forma moderna, clara e profissional.

---

## 📌 Funcionalidades

- Página institucional com informações sobre a empresa
- Apresentação de serviços contábeis
- Formulário de contato funcional
- Design responsivo (adaptável a celulares e tablets)
- Código limpo e estruturado com **Bootstrap 5**

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (interações básicas)
- PHP (para backend leve, se necessário)
- Hospedado via XWeb Sites
